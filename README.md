# Библиотечный учет

Вариант № 3 — «Библиотека учебного заведения».

Интернет-приложение для учета библиотечного фонда, читателей,
выдач и возвратов экземпляров изданий.

Предусмотрены две роли пользователей: библиотекарь и читатель.

## Практическая работа № 1

Техническое задание на разработку интернет-приложения.

Разработано техническое задание по ГОСТ 34.602-2020.

- Определены роли пользователей и функциональные требования.
- Спроектирована модель базы данных.
- Разработаны макеты пользовательского интерфейса.
- Определены сценарии приемки системы.

[Техническое задание (PDF)](docs/technical-specification.pdf)

## Практическая работа № 2

Клиентская часть интернет-приложения.

- Реализованы регистрация, вход и выход из системы.
- Разработан каталог изданий с поиском, фильтрацией,
  сортировкой и постраничным выводом.
- Реализованы просмотр, добавление, редактирование и удаление изданий.
- Реализован учет экземпляров и читателей.
- Реализованы оформление выдач и возвратов,
  просмотр собственных выдач читателем.
- Разработаны семь основных экранов и страница 404.
- Созданы переиспользуемые компоненты интерфейса.
- Реализованы проверка ввода и разграничение интерфейса по ролям.
- Обращения к данным вынесены в отдельный модуль.
- Подготовлены демонстрационные данные, включающие 15 изданий.
- Проверены адаптивность интерфейса и запуск из чистой копии репозитория.

На данный момент приложение работает с локальными данными,
изменения сохраняются в оперативной памяти и сбрасываются
при перезагрузке страницы.

## Запуск приложения

Для запуска необходимы Node.js и npm.
Работоспособность проверена с Node.js 24.22.3 и npm 11.19.1.

Клонирование репозитория:

```bash
git clone https://github.com/Diss2D/library-accounting.git
cd library-accounting/frontend
```

Установка зависимостей:

```bash
npm ci
```

Запуск приложения:

```bash
npm run dev
```

Приложение доступно по адресу: http://localhost:5173/

Сборка приложения:

```bash
npm run build
```

Проверка собранного приложения:

```bash
npm run preview
```
