# Библиотечный учет

Вариант № 3 — «Библиотека учебного заведения».

Интернет-приложение для учета библиотечного фонда, читателей,
выдач и возвратов экземпляров изданий.

Предусмотрены две роли пользователей: библиотекарь и читатель.

## Практическая работа № 1

Техническое задание на разработку интернет-приложения.

Разработано техническое задание по ГОСТ 34.602-2020.

- Определены роли пользователей и функциональные требования.
- Спроектирована модель базы данных.
- Разработаны макеты пользовательского интерфейса.
- Определены сценарии приемки системы.

[Техническое задание (PDF)](docs/technical-specification.pdf)

- Созданы переиспользуемые компоненты интерфейса.

- Обращения к данным вынесены в отдельный модуль.
- Подготовлены демонстрационные данные, включающие 15 изданий.
- Проверены адаптивность интерфейса и запуск из чистой копии репозитория.

## Практическая работа № 3

Серверная часть, CRUD-операции и база данных.

- Создан сервер на FastAPI и база данных PostgreSQL из пяти связанных таблиц.
- Настроены миграции Alembic и скрипт начального наполнения базы.
- Подготовлены 30 изданий, экземпляры, читатели, учетные записи и история выдач.
- Реализованы регистрация, вход, хеширование паролей Argon2id и JWT-аутентификация.
- Реализованы CRUD-операции изданий, учет экземпляров и читателей, выдачи и возвраты.
- Реализованы серверная фильтрация, сортировка, пагинация и проверка данных.
- Права библиотекаря и читателя проверяются на сервере.
- Клиентский слой данных использует HTTP-запросы к API вместо локальных JSON-файлов.
- Выдачи и возвраты оформляются в модальных окнах, список выдач поддерживает
  серверный поиск, фильтрацию по состоянию, сортировку и постраничный вывод.
- Собственные выдачи читателя отображаются постранично.
- Изменения сохраняются в PostgreSQL, сеанс сохраняется при перезагрузке страницы,
  JWT действует два часа, выход очищает сеанс.

## Запуск приложения

Необходимы Python 3.12, PostgreSQL 16, Node.js 24 и npm.
Для разработки используется Ubuntu 24.04.

### Подготовка проекта

```bash
sudo apt update
sudo apt install -y git python3-venv postgresql
sudo service postgresql start

git clone https://github.com/Diss2D/library-accounting.git
cd library-accounting
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r backend/requirements.txt
```

### Настройка базы данных

Сгенерировать пароль пользователя PostgreSQL:

```bash
python -c "import secrets; print(secrets.token_hex(16))"
```

Создать отдельного пользователя и базу, пароль, при запросе,
вводится дважды:

```bash
sudo -u postgres createuser --pwprompt library_user
sudo -u postgres createdb -O library_user library_accounting
```

Создать локальный файл настроек и сгенерировать секрет для JWT:

```bash
cp backend/.env.example backend/.env
chmod 600 backend/.env
python -c "import secrets; print(secrets.token_hex(32))"
```

В `backend/.env` заменить `CHANGE_ME` в `DATABASE_URL` на пароль пользователя
PostgreSQL, а `CHANGE_ME` в `JWT_SECRET` на сгенерированный секрет.
`FRONTEND_ORIGIN` задает разрешенный адрес клиента, по умолчанию
`http://localhost:5173`. Для тестовых учетных записей
`DEMO_PASSWORD=demo1234`.

Настоящий `.env` в Git не добавляется.

Создать схему и наполнить пустую базу:

```bash
alembic -c backend/alembic.ini upgrade head
python -m backend.seed
```

Повторный запуск скрипта наполнения не дублирует записи.

### Запуск серверной части

Из корня проекта с активным виртуальным окружением:

```bash
uvicorn backend.main:app --reload
```

Адрес API: http://127.0.0.1:8000/api/v1/.
Документация Swagger UI: http://127.0.0.1:8000/docs.

### Запуск клиентской части

В отдельном терминале из корневой директории проекта:

```bash
cd frontend
npm ci
npm run dev -- --strictPort
```

Открыть http://localhost:5173/.

По умолчанию клиент обращается к `http://127.0.0.1:8000/api/v1`.
Если адрес API отличается, нужно скопировать `frontend/.env.example` в
`frontend/.env` и изменить `VITE_API_URL`. При изменении адреса клиента
также нужно изменить `FRONTEND_ORIGIN` на сервере и перезапустить приложения.

Сборка клиентской части:

```bash
npm run build
```

Проверка собранного приложения:

```bash
npm run preview -- --port 5173 --strictPort
```

Сервер FastAPI и PostgreSQL должны оставаться запущенными.
Для остановки FastAPI и Vite в терминале используется `Ctrl+C`.
